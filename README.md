# DownPilot-Download-Manger
🚀 DownPilot v1.0.0 - First Release

A powerful, fast download manager for Windows that combines regular downloads and torrents in one app.

✨ Key Features

⚡ Blazing Fast Downloads

Multi-connection file splitting for maximum download speed
Automatic clipboard link detection — copy a link and downloading starts instantly

🧲 Full BitTorrent Support

Download via torrent files and Magnet links
Preview torrent contents (files and size) before downloading, with the option to select only the files you need
Fast DHT and Tracker connectivity for instant metadata retrieval

🎛️ Full Download Control

Automatic scheduling (global or per-task)
Speed limiting (global or per-task)
Priority-based queue system for managing multiple downloads at once

🖥️ Sleek, Practical Interface

Independent progress window for each download with a modern design and quick-access menu bar
Full Dark / Light mode support

🔄 Reliability & Startup

Optional auto-start with Windows, with silent start-to-tray option
Automatic update system that checks for new releases and installs them in one click
💻 System Requirements
Windows 10 (Build 17763 or later) or Windows 11
